# Economy Model

## Philosophy
- No pay-to-win mechanics
- Cosmetics only: skins, powder trails, dojo banners
- Earned currency through match participation and milestones

## Currency Types
- **Flow** — earned in-match, spent on cosmetics
- **Mark** — earned through ranked milestones, permanent record

## Anti-Exploit
- All economy events pass through server-authoritative event pipeline
- Client cannot self-report earnings
- Rate limiting enforced at service layer
